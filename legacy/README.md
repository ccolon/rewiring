# legacy/

Archive of older launchers, plotters, and exploratory scripts that produced
data or figures predating the consolidated `campaigns/` structure. Kept
here for reproducibility: the CSVs in `results/` (gitignored) for several
canonical figures were generated by these scripts. The canonical campaign
launchers under `campaigns/<name>/launch.sh` reproduce the same data with
cleaner, comprehensive recipes.

Nothing here is run by the current canonical workflow. Files retain their
original docstrings and contents; no path patches were applied.

## Layout

- `diversity/` -- older diversity launchers (4panel, 6panel, 3 topups) and
  the early 4-panel / 6-panel plotters. Their CSVs feed
  `figure_diversity.png` and `figure_diversity_ms4.png`.
- `visibility/` -- older visibility launchers (R1, R2/R3 hetero, noaisi/nosw
  followup, etc.), the older `visibility_study.py`, the 2-panel plotter,
  and `audit_perfirm.py`. The first three launchers' CSVs feed panels
  (a) and (b) of `figure_visibility.png`.
- `cost/` -- older cost-gap launchers and the cost-reduction analyzer.
  `launch_cost_static.sh` (+ `_tau1` topup) produced the data feeding
  panel (c) of `figure_visibility.png`. `launch_cost_static_opAB.sh`,
  `launch_cost_reduction*.sh`, and `analyze_cost_reduction.py` are
  exploratory or superseded.
- `diversity_size/` -- launcher + plotter for the non-canonical
  `figure_diversity_size.png`.
- `local_continuity/` -- analyzer for an exploratory continuity study.
- `exploratory/` -- generic followups, broader sweeps, and per-firm
  diagnostic studies that did not land in any canonical figure.

## What was deleted (not archived)

- `scripts/one_run.py` -- single-trial debug script with a broken import.
- `results/visibility/launch_visibility.sh` -- byte-identical duplicate of
  the version archived under `legacy/visibility/`.
- `results/visibility/launch_visibility_noaisi_nosw_followup.sh` -- same.
